## 2. الألوان (مستخرجة من الشعار)

| الدور | تقريب لوني | استخدام |
|--------|------------|---------|
| Primary Dark / Burgundy | `#4A0404` → `#6B0012` | خلفيات داكنة، هيرو، تدرجات |
| Accent Gold | `#D4AF37` / `#C9A227` | أزرار CTA، عناوين مميزة، حدود، أيقونات |
| Gold Soft / Fabric | `#E8D5A3` تقريباً | تفاصيل خفيفة، هوفر |
| Admin Primary (NexLink) | `#5955D1` | يبقى للوحة NexLink ما لم يُطلب توحيد كامل |
| نص على داكن | `#F5F0E6` / أبيض دافئ | نصوص اللاندينغ |
| نص ثانوي | ذهب شفاف / رمادي دافئ | وصف قصير |

### توصية للمبرمج

- **اللاندينغ:** اعتماد عنابي + ذهبي من الشعار (هوية فاخرة).
- **لوحة الإدارة (NexLink):** الإبقاء على سيكل NexLink Dark؛ استبدال الشعار والنصوص بـ استوديو الراية. توحيد اللون الأساسي إلى الذهبي/العنابي **اختياري** لاحقاً حتى لا نكسر مكوّنات الثيم.

متغيرات CSS مقترحة للاندينغ:

```css
:root {
  --brand-burgundy: #4A0404;
  --brand-burgundy-deep: #2E0101;
  --brand-gold: #D4AF37;
  --brand-gold-soft: #E8D5A3;
  --brand-cream: #F5F0E6;
}
```

## 3. الطباعة

| السطح | الخط |
|--------|------|
| Admin (NexLink) | **Cairo** (إلزامي — قراءة عربية أوضح) |
| لاندينغ — عربي عرض | خط عربي فاخر للعرض (يُختار عند التنفيذ؛ قريب من روح الشعار) |
| لاندينغ — نصوص | خط عربي مقروء + لاتيني متناسق |
| الإنجليزية في البراند | Serif للـ ALRAYA كما في الشعار حيث يناسب |

الاتجاه دائماً: `lang="ar" dir="rtl"` للواجهات العربية.

---

## 4. نبرة الهوية

- فاخر، احترافي، مناسبات (أعراس / توثيق)
- جملة الشعار: «علامة الجودة والاحتراف»
- تجنب مظهر CRM عام على الصفحة العامة؛ الفخامة للاندينغ، والتنظيم للأدمن

## 5. تواصل اجتماعي وواتساب (واجهة عامة)

| العنصر | المواصفة |
|--------|----------|
| زر واتساب عائم | دائري، لون واتساب الأخضر أو ذهبي متناسق مع البراند، ثابت أسفل الشاشة |
| أيقونات السوشيال | فوتر؛ ذهبية/كريمية على خلفية عنابية |
| المصدر | قيم من إعدادات الأدمن — لا تُ硬-كود في الواجهة |
| إخفاء | إن كان الرابط فارغاً لا تُعرض الأيقونة |
