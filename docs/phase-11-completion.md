# سجل إنجاز المرحلة 11 — تقارير Excel/PDF

> التاريخ: 2026-08-16  
> المهندسة: نهلة البستنجي

---

## الخلاصة

فهرس تقارير من MySQL: مناسبات، دفعات، خصومات، طاقم، عروض. التصدير CSV UTF-8 يفتح في Excel، والـ PDF عبر طباعة المتصفح. بدون حزمة npm جديدة. POS خارج النطاق.

---

## ما بُني

| العنصر | المسار |
|--------|--------|
| الفهرس | `/admin/reports` |
| المناسبات | `/admin/reports/events` |
| الدفعات | `/admin/reports/payments` |
| الخصومات | `/admin/reports/discounts` |
| خدمات الموظفين | `/admin/reports/staff` |
| العروض | `/admin/reports/offers` |
| تصدير CSV | `GET /api/admin/reports/[kind]` |
