# بيانات دخول تجريبية — محلي فقط

> لا ترفعي كلمات المرور الحقيقية للإنتاج هنا.  
> **موجة A / مرحلة 14:** ممنوع تشغيل `db:seed` على سيرفر إنتاج/مشترك — غيّري كلمات المرور فوراً إن وُجدت.

| الدور | البريد | كلمة المرور |
|--------|--------|-------------|
| مدير الأستوديو (يدخل اللوحة) | `admin@alray.studio` | `Admin@123456` |
| مساعد (تعيين على المواعيد فقط) | `staff@alray.studio` | **لا دخول** — بلا كلمة مرور |

الرابط: http://localhost:3000/admin/login

**قرار المرحلة 15:** دخول `/admin` لحساب المسؤول فقط. الطاقم يظهر في قائمة الموظفين ويُعيَّن على موعد بدون login.  
**ملاحظة:** دور «مصور» أُلغي من الأدوار — الطاقم بدور «مساعد» (أو أدوار تضيفينها يدوياً).

```bash
cd apps/web
npm run db:seed
```
