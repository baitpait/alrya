## أسلوب «من يدخل؟»

دور ثابت بالاسم: **`مدير الأستوديو`** (`MANAGER_ROLE_NAME` في `lib/roles.ts`).  
لا حقل `canLogin` منفصل — دخول اللوحة = نفس شرط المسؤول.

## ما تغيّر

| بند | التنفيذ |
|-----|---------|
| 15.0 | `loginWithCredentials` يرفض غير المسؤول: «الدخول مسموح لحساب المسؤول فقط.» |
| 15.1 | جلسة غير مسؤول تُمسح · middleware يحوّل للّوجين · API أدمن 403 |
| 15.2 | `getVerifiedSession` يفحص `User.active` + الدور |
| 15.3 | Server Actions تبقى خلف `requireManager` |

| مناسباتي | رابط السايدبار للمسؤول فقط (الطاقم لا يدخل أصلاً) |
