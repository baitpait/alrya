# إجراءات صفوف الأدمن — أيقونات مناسبة للمصطلح

> قرار مدير المشروع: مصطفى البستنجي — **2026-08-17**  
> المكوّنات: `AdminActionIcons` · `ConfirmDelete` · `AdminBackLink`  
> الأنماط: `admin-shell.css`

---

## قاعدة ذهبية

**الأيقونة يجب أن تطابق معنى المصطلح.**  
لا تستخدمي «عين» لفتح التقويم، ولا «مجلد» لفتح المناسبة إن وُجدت أيقونة أوضح.

| المصطلح / الإجراء | `kind` | الشكل |
|-------------------|--------|--------|
| عرض / تفاصيل عامة | `view` | عين |
| تعديل | `edit` | قلم |
| فتح ملف/كيان عام مرتبط | `open` | مجلد |
| **فتح التقويم** | `calendar` | تقويم |
| **فتح المناسبة** | `event` | تقويم + علامة صح |
| **التقارير** | `reports` | أعمدة رسم بياني |
| حذف | `ConfirmDelete` | سلة |

```tsx
<ActionIconLink href="/admin/calendar" label="فتح التقويم" kind="calendar" />
<ActionIconLink href={`/admin/events/${id}`} label={`فتح المناسبة #${id}`} kind="event" />
```

---

## 1) روابط الرجوع — أزرار

```tsx
<AdminBackLink href="/admin/messages" label="رجوع للرسائل" />
```

ممنوع: `<Link className="text-link">← رجوع…</Link>`

---

## 2) جداول وإجراءات

- كل أيقونة: `title` + `aria-label` بالعربية.
- حذف: `ConfirmDelete` + تأكيد · `fieldName="recordId"` (لا `name="id"`).
- شريط أدوات الصفحة (مثل لوحة التحكم): أيقونة تقويم/تقارير بدل نص `text-link`.

---

## 3) لوحة التحكم (مثال معتمد)

| قبل | بعد |
|-----|-----|
| رابط «فتح التقويم» | `kind="calendar"` |
| رابط «المناسبة» في المواعيد القادمة | `kind="event"` |
| رابط «التقارير» تحت العنوان | `kind="reports"` |

---

## 4) اختبار يدوي

1. لوحة التحكم → أيقونة تقويم تفتح `/admin/calendar` · التلميح «فتح التقويم».  
2. صف موعد قادم → أيقونة مناسبة تفتح تفاصيل المناسبة.  
3. لا نصوص «عرض» / «المناسبة» / «فتح التقويم» كنص تحتي في عمود الإجراءات.
