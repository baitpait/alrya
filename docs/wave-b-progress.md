## إصلاح واجهة الطاقم (بعد الموجة)

المشكلة: بعد Wave B المصور كان يشوف بطاقات المدير في لوحة التحكم (زبائن/دفعات/تقارير…) ويضغط ويروح مناسباتي — حسّ إنه النظام مكسور.  
الإصلاح: داشبورد للطاقم فقط · إخفاء إنشاء/تعديل المناسبات والتقويم عن غير المدير · تفاصيل مناسبة قراءة فقط للطاقم.

## اختبار يدوي

1. اخرجي وادخلي كمدير `admin@alray.studio` — القائمة كاملة + إضافة موعد على التقويم
2. ادخلي كمصور `photographer@alray.studio` / `Photo@123456` — **لوحته بدون زبائن/دفعات/تقارير** · فقط مناسبات/مواعيدي/تقويم
3. التقويم كمصور: يشوف المواعيد، **بدون** زر إضافة ولا نموذج تعديل
4. المناسبة كمصور: عرض فقط — بدون نماذج دفعات/تعيين
5. `/admin/employees` كمصور → تتحولين لمناسباتي
6. عطّلي حساب المصور من المدير → دخوله أو تصفح الأدمن يفشل
7. `/api/admin/calendar/events` بدون تسجيل → 401

بعد **نجحت**: إشعار + رفع.
