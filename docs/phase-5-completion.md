## الخلاصة

شاشة `/admin/calendar` تعرض كل `EventService` من MySQL (عنوان: خدمة — زبون)، مع إضافة/تعديل موعد حقيقي وظهور فوري بعد الحفظ وRefresh. RTL + Light/Dark.
