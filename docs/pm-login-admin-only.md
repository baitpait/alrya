## القرار بجملة

**المصورون والمساعدون = طاقم تعيين على المواعيد فقط.**  
**تسجيل الدخول إلى `/admin` مسموح فقط لحساب «مسؤول / مدير الأستوديو».**

لا نريد أن يعمل موظف الطاقم login للنظام.

---

## الوضع الحالي (مشكلة)

| الواقع الآن | المطلوب |
|-------------|---------|
| كل `User` له بريد + كلمة مرور ويمكنه الدخول إن كان `active` | الدخول فقط لدور المسؤول |
| نموذج إضافة موظف يطلب كلمة مرور دائماً | طاقم (مصور/مساعد): **بدون** دخول — لا كلمة مرور للدخول |
| «مناسباتي» تفترض أن الموظف يدخل بحسابه | إما تُخفى من القائمة للطاقم (لأنهم لا يدخلون) أو تبقى للمسؤول فقط إن لزم |

ملفات مرتبطة للنظر:
- `lib/auth.ts` — `loginWithCredentials`
- `app/admin/(panel)/employees/page.tsx` · `[id]/page.tsx` · `actions.ts`
- `prisma/schema.prisma` — `User` / `Role`
- سايدبار: رابط «مناسباتي»

## المطلوب من المبرمج (مرحلة 15)

### أ) منتج / منطق
1. عرّفي من هو **مسؤول يدخل**: دور باسم ثابت مثل `مدير الأستوديو` **أو** حقل على الدور مثل `canLogin` / `isAdmin` (اختاري أسلوباً واحداً ووثّقيه).
2. عند **login**: إن المستخدم ليس مسؤولاً → ارفضي الدخول برسالة واضحة بالعربية (مثال: «الدخول مسموح لحساب المسؤول فقط.») — حتى لو كانت كلمة المرور صحيحة.
3. طاقم التصوير/المساعدة:
   - يبقى في قائمة الموظفين للتعيين على موعد (حنا / عرس…).
   - **لا يُمنح دخول** للوحة.
4. عند إضافة/تعديل موظف بدور غير مسؤول: لا تطلبي كلمة مرور للدخول (أخفي الحقل أو اجعليه غير مطلوب). للمسؤول فقط: بريد + كلمة مرور إلزاميان.

### ب) واجهة
- نص توضيحي تحت عنوان الموظفين:  
  «الطاقم للتعيين على المواعيد. دخول اللوحة للمسؤول فقط.»
- لا أزرار صامتة · لغة عربية بدون مصطلحات تقنية (`docs/admin-ui-copy.md`).

### ج) مناسباتي
- بما أن الطاقم لا يدخل: أخفي رابط «مناسباتي» من السايدبار **أو** أبقيه للمسؤول فقط إن كان له تعيينات. لا تعتمد على دخول المصور.

### د) اختبار يدوي إلزامي
| # | الاختبار | نتيجة |
|---|----------|--------|
| L1 | دخول `admin@…` (مسؤول) ينجح | |
| L2 | حساب مصور/مساعد (إن وُجدت له كلمة قديمة) **يرفض** الدخول | |
| L3 | إضافة مصور جديد بدون كلمة مرور للدخول — يظهر في القائمة ويُعيَّن على موعد | |
| L4 | بعد التعيين يظهر في تفاصيل المناسبة والتقويم كما سابقاً | |
| L5 | لا رابط سايدبار يفتح لوحة لغير مسؤول | |
