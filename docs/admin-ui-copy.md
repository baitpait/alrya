# لغة واجهة الأدمن — بدون مصطلحات تقنية

> قرار مدير المشروع: مصطفى البستنجي — **2026-08-17**  
> للمبرمج / الوكيل: النصوص الظاهرة للمستخدم ≠ تعليقات الكود أو أسماء الجداول.

---

## القاعدة

**ممنوع** ظهور أسماء تقنية إنجليزية أو داخلية في واجهة الأدمن (أو الموقع العام)، مثل:

| ممنوع في الواجهة | بديل عربي مقبول |
|------------------|-----------------|
| `EventService` | موعد / خدمة بتاريخ / موعد على التقويم |
| `MySQL` / `Prisma` / `DB` | النظام / السجل / البيانات المحفوظة |
| `Inbox` | طلبات الحجز / صندوق الطلبات |
| `CSV` (كتفسير للمستخدم) | ملف Excel / تصدير Excel |
| `FullCalendar` / `API` / `Server Action` | لا تُذكر للمستخدم |
| `PENDING` وأمثالها كنص ظاهر | استخدم التسمية العربية (جديد / محوّل…) |

التعليقات داخل ملفات `.ts` وأسماء الدوال (`addEventService`) **مسموحة** — للمبرمج فقط.

---

## أمثلة أُصلحت (2026-08-17)

| قبل | بعد |
|-----|-----|
| يُنشأ EventService حقيقي ويظهر فوراً على التقويم | يُحفظ الموعد ويظهر فوراً على التقويم |
| كل المواعيد من EventService في قاعدة البيانات… | كل المواعيد من سجل الاستوديو… |
| أرقام حية من MySQL | أرقام حية من النظام |
| Inbox الحجوزات من اللاندينغ | طلبات الحجز من الموقع |
| خدمات بتاريخ (EventService) | مواعيد خدمات بتاريخ (مثل حنا وعرس) |

## للمبرمج قبل أي نص مساعدة تحت العنوان

1. اسألي: هل صاحب الاستوديو يفهم الجملة بدون خلفية برمجة؟  
2. إن احتجتِ شرحاً تقنياً — ضعيه في `docs/` أو تعليق كود، **لا** في `<p>` تحت العنوان.  
3. راجع `.cursor/rules/admin-tables-ux.mdc` (§ لغة الواجهة).
